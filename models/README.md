# Model files

`Xenova/all-MiniLM-L6-v2` is the ONNX export of [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2), downloaded unchanged from [huggingface.co/Xenova/all-MiniLM-L6-v2](https://huggingface.co/Xenova/all-MiniLM-L6-v2). Only the 8-bit quantized weights (`onnx/model_quantized.onnx`) are included.

The model is licensed under the Apache License 2.0, a copy of which is in `LICENSE-APACHE-2.0.txt`. The rest of Shoebox is MIT licensed.

They're served from this site so Shoebox doesn't depend on a third-party model host at runtime.
